# Portfolio Website

This repository contains a basic Flask application that serves as a portfolio website. The site includes the following pages:

1. Home page
2. Blogs listing and single blog post
3. Case Studies listing and single case study
4. Services listing and single service
5. About page
6. Contact page
7. Terms of Service
8. Privacy Policy

## Setup

1. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python run.py
   ```

Run `pytest` to execute the basic tests.
